# Prompt Guide

Use these prompt shapes when working in this writing workspace.

## Canon Lookup

```text
Use the fanfic tools first. Tell me where 任隊長 is first mentioned before he appears, and cite chapter and paragraph.
```

## Chapter Refresh Before Writing

```text
Use the fanfic tools first. Fetch the full summary of Chapter_16, then give me the canon constraints I must preserve before writing the next confrontation scene.
```

## Exact Prose Check

```text
Use the fanfic tools first. Fetch the full text of Chapter_16 and help me match its tone and scene pacing without copying sentences directly.
```

## Drafting With Canon Guardrails

```text
Use the fanfic tools first. Check the canon constraints for 林妍 and 任隊長 before this scene, then draft a new scene in Traditional Chinese. Separate canon-backed facts from your invented additions.
```

## Continuity Review

```text
Use the fanfic tools first. Review this draft for canon or continuity problems. List the problems first, then suggest fixes.
```

## Quote Verification

```text
Use the fanfic tools first. Verify whether this quote appears in Chapter_16 paragraph 18. If not, say so directly.
```
